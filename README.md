# Fête de la Science: a robot learning to walk among people

A laptop demo for a science fair. A visitor drags a slider over training and watches a robot go from
crashing into people to crossing a crowded room politely. The viewer only plays back trajectories
exported beforehand; nothing is trained or computed in the browser, and nothing is fetched from the
internet.

```bash
./run.sh                 # local web server + browser, http://localhost:8000/index.html
```

`run.bat` does the same on Windows. Opening `viewer/index.html?simple=1` as a file also works, with
simple shapes instead of the 3D characters, as a fallback if the models misbehave on the stand laptop.

The demo is in French. The "?" button in the corner opens the presenter guide, also available as
[`GUIDE_ANIMATEUR.md`](GUIDE_ANIMATEUR.md).

## What is shown

CrowdNav's SARL policy trained in SocNavGym: a 10 x 10 m room, 6 walking people who do not step aside
for the robot, and a goal to reach. The slider steps through 22 checkpoints, from the untrained
network to 13 000 training episodes. Layers can be shown or hidden: the moves the robot weighs, its
attention over people, personal-space models, people's reactions, the reward rules, learning curves.

## Layout

| Path | What it is |
|---|---|
| `viewer/` | The demo: plain HTML, CSS and JavaScript, three.js vendored in `viewer/vendor/`, characters in `viewer/assets/`. No build step. |
| `viewer/data.js` | The trajectories the viewer plays, generated by `bundle_data.py`. |
| `training/` | Scenario, SARL training, evaluation. See [`training/README.md`](training/README.md). |
| `sarl_one_room/` | Exported trajectories for the room shown in the demo (seed 5), the source of `viewer/data.js`. |
| `sarl_real_data/` | The same checkpoints exported over 8 rooms. |
| `export_trajectories.py` | Replays checkpoints and writes the export, then rebuilds `viewer/data.js`. |
| `bundle_data.py` | Packs an export directory into `viewer/data.js`. |
| `tools/prune_gltf.py` | Used once to trim the character models to their walk and idle animations. |
| `SCHEMA.md` | The trajectory data format. |
| `ASSETS.md` | Source and licence of three.js and of every 3D model. |

## Rebuilding the data

```bash
conda activate socnavgym
python export_trajectories.py training/runs/sarl_humans/checkpoints --seeds 5
```

Use `--seeds 5 9 12` for several rooms, or `python bundle_data.py sarl_real_data` to switch the viewer
to an export that already exists.
